GSINFO — VERSION 2
==================

Fichiers :
- index.html : page du site
- style.css : design bleu nuit et cyan, responsive
- script.js : petite fonction d'affichage de l'année

Publication GitHub Pages :
1. Décompressez le ZIP.
2. Dans le dépôt GitHub public "mon-site", onglet Code > Add file > Upload files.
3. Téléversez index.html, style.css et script.js directement à la racine (pas le dossier).
4. Cliquez sur Commit changes.
5. Settings > Pages : Deploy from a branch, main, /(root), Save.
6. Attendez le déploiement puis ouvrez https://gsinfo2.github.io/mon-site/
